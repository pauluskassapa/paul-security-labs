# Project 04 - Networking Fundamentals

## Objective

Build a strong foundation in computer networking for IT Infrastructure and Blue Team Cybersecurity.

## Lessons

- Lesson 1 - Network Basics
- Lesson 2 - OSI Model
- Lesson 3 - TCP/IP Model
- Lesson 4 - IP Addressing
- Lesson 5 - DNS
- Lesson 6 - DHCP & NAT
- Lesson 7 - Common Protocols
- Lesson 8 - Wireshark Fundamentals
- Lesson 9 - Packet Analysis
- Lesson 10 - Network Investigation Mini Project

## Environment

- macOS
- Windows 11 ARM
- Ubuntu 24.04 LTS
- VMware Fusion Pro
- Wireshark
- PowerShell

## Lesson 1 - Network Basics

### Topics

- Network Fundamentals
- LAN
- WAN
- Internet
- Router
- Switch
- Modem
- Access Point

### Hands-on

- Checked IP configuration
- Identified default gateway
- Performed DNS lookup
- Identified public IP address

### Result

Learned the basic concepts of computer networking and how devices communicate through local networks and the Internet.

## Lesson 2 - OSI Model

### Topics

- OSI 7 Layer Model
- Layer Functions
- Common Protocols
- Real-world Networking

### Hands-on

- Checked IP configuration
- DNS lookup
- Ping test
- Traceroute

### Result

Learned how the OSI model explains data communication and related networking tools to different layers.\

## Lesson 3 - TCP/IP Model

### Topics

- TCP/IP Model
- TCP vs UDP
- IPv4 & IPv6
- Common Ports

### Hands-on

- Checked IPv4 and IPv6 configuration
- Tested TCP connectivity
- Identified active ports using netstat

### Result

Learned the TCP/IP model, the differences between TCP and UDP, common network ports, and how to inspect network connections in Windows.
